# [DP Investor Club 2기] 첫 수업(7/10 금) 사전 준비 안내

안녕하세요, DP Investor Club 2기 여러분.

첫 AI Intensive 수업(7/10 금 13:00–16:00)에서는 각자 노트북으로 **본인의 투자 리서치 작업환경**을 직접 만듭니다. 수업 시간을 온전히 실습에 쓰기 위해, 아래 준비를 수업 전까지 완료해 주시기 바랍니다. **소요 시간은 15~20분**입니다.

---

## 준비 체크리스트 (4단계)

### 1. Claude 계정 + Pro 구독 확인

- [claude.ai](https://claude.ai) 에서 로그인이 되는지 확인합니다.
- 구독은 **Pro 요금제**면 5주 과정 전체에 충분합니다. 아직 구독 전이라면 Pro로 시작해 주세요.

### 2. Claude Code 설치

터미널(Mac: Terminal / Windows: PowerShell)을 열고 아래 한 줄을 붙여넣어 실행합니다.

- **Mac**
  ```
  curl -fsSL https://claude.ai/install.sh | bash
  ```
- **Windows (PowerShell)**
  ```
  irm https://claude.ai/install.ps1 | iex
  ```

별도 프로그램 설치는 필요 없습니다. 설치가 끝나면 터미널을 한 번 닫았다가 다시 열어 주세요.

> Windows에서 "실행 정책" 오류가 나오면, 아래를 먼저 실행한 뒤 다시 시도합니다.
> `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser`

### 3. GitHub 계정 만들기

- [github.com](https://github.com) 에서 무료 계정을 만듭니다 (이미 있다면 로그인 확인만).
- 수업에서 리서치 작업물을 보관하고 제출하는 데 사용합니다. 개발 지식은 필요 없습니다.

### 4. 설치 확인

터미널에서 아래를 실행합니다.

```
claude
```

로그인 안내가 나오면 Claude 계정으로 로그인하고, 채팅 화면이 뜨면 "안녕"이라고 한 마디 보내 보세요. 답이 돌아오면 준비 완료입니다. 완료하신 분은 Slack 공지 메시지에 ✅ 이모지로 알려 주세요.
