# Check-in — 매주 방향 점검

채민이 직접 만든 스킬 (club 소유 스킬 아님, `/update`가 건드리지 않는다).

## 절차

1. `journey.md`의 "나의 선언"과 "나의 진행 상태" 표, "세션 노트" 섹션을 읽는다.
2. `outputs/` 디렉터리를 읽고 이번 주에 새로 생긴 산출물이 있는지 확인한다. 없으면 "이번 주 산출물 없음"으로 취급하고 넘어간다 (없다고 다그치지 않는다).
3. AskUserQuestion으로 아래 두 질문을 던진다 (가설을 선택지로):
   - "이번 주 지은 것/본 것을 보면, '나의 선언'이 여전히 맞다고 느끼나요?"
     옵션: 그대로 맞음 / 조정이 필요할 것 같음 / 아직 판단하기 이르다
   - "이번 주 진행에서 막힌 지점이 있었나요?"
     옵션: 없음 — 순조로움 / 있음 — 방향(뭘 봐야 할지 모르겠다) / 있음 — 실행(도구·기술적으로 막힘)
4. 답을 받으면, 참가자의 말을 그대로 받아 적어 `journey.md`의 "## 세션 노트" 섹션 맨 아래에 한 줄을 추가한다:
   ```
   - {YYYY-MM-DD} 체크인: {선언 상태 요약} / {막힌 지점 요약}
   ```
5. 대필 금지 — 참가자가 고른 옵션과 덧붙인 말을 그대로 옮긴다. 막힌 지점이 있다고 답하면 다음 세션에서 무엇부터 풀지 한 문장만 같이 남긴다.

## 규칙

- 투자 의견(종목·목표가)에는 관여하지 않는다 — 이 스킬은 방향 점검용이지 투자 판단 도구가 아니다.
- journey.md의 "나의 선언" 문구 자체는 수정하지 않는다 (그건 `/clarify`의 역할). 체크인은 기록만 남긴다.
- 매주 한 번, 가볍게 — 질문 2개면 충분하다. 길게 캐묻지 않는다.
