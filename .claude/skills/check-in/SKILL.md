# Check-in — 매주 방향 점검

## 절차

1. `journey.md`의 "나의 선언"과 "세션 노트"의 가장 최근 check-in 기록을 읽는다.
2. `outputs/` 폴더가 있으면 이번 주 파일들을 확인한다. 없으면 "이번 주 산출물 없음"으로 취급한다.
3. AskUserQuestion으로 묻는다 (각 질문은 참가자의 말을 그대로 받아 적는다 — 대필 금지):
   - 지난주(또는 선언 당시)와 비교해 내 방향이 어떻게 움직였나요? (그대로다 / 더 선명해졌다 / 바뀌었다 / 모르겠다)
   - 이번 주 강연·수업에서 내 방향에 걸리는 게 있었나요? (있으면 한 줄로)
4. 답을 받으면 `journey.md`의 "세션 노트" 섹션에 아래 형식으로 한 줄 추가한다:
   ```
   - {날짜} check-in: {방향 변화 답변} / 강연에서 걸린 것: {두 번째 답변 또는 "없음"}
   ```

## 규칙

- 참가자가 "모르겠다"고 답해도 억지로 결론을 만들지 않는다 — 그대로 기록한다.
- 이 스킬은 판단을 대신하지 않는다. 방향이 움직였는지 되묻고 기록만 한다.

## 확장: 산업 진입점 찾기 (방대한 주제에 진입할 때)

산업·주제가 너무 방대해서 어디부터 봐야 할지 모를 때 쓴다. 혼자 정하지 않는다 — **짝과의 토론에서 나온 답을 그대로 출력 스펙으로 쓴다.**

### 절차

1. 지금 막막한 대상(산업/주제)을 확인한다.
2. 참가자에게 짝에게 이 질문을 소리 내어 던지게 안내한다: **"첫 30분에 뭘 알면 시작한 기분이 들어?"**
3. 짝의 답을 참가자가 전달하면, 그 말을 그대로 받아 적는다 — 다듬거나 대신 요약하지 않는다 (대필 금지).
4. 그 답을 그대로 "첫 30분 체크리스트"로 확정하고, 참가자에게 확인시킨다: "이게 첫 30분 체크리스트 맞나요?"
5. 확정되면 `context.md`의 "다음 소스 액션"에 아래 형식으로 append 한다 (기존 내용 수정 금지):
   ```
   - ({날짜}) {대상 산업/주제} 첫 30분 체크리스트: {짝의 답 그대로}
   ```

### 규칙

- 이 체크리스트는 AI가 만들지 않는다 — 짝의 답을 옮겨 적는 것뿐이다. AI가 "이런 것도 있지 않을까요"로 채워 넣지 않는다.
- 산업 전체를 커버하려 하지 않는다. "첫 30분"이 기준이다 — 완주선은 방대함 해소가 아니라 시작점 하나다.
