# Dreamplus Lecture Notes — 강연 노트 정리

노션 [드림플러스 investor club] 페이지의 최신 강연을 읽고, 민소가 나중에 다시 찾아 쓸 수 있는 인사이트 노트로 저장한다. 이건 참가자 개인 스킬이다 — 강연 원문을 옮기는 게 아니라 **판단에 쓸 수 있는 형태**로 가공하는 게 목적이다.

## 절차

1. **노션에서 강연 찾기**
   - `mcp__claude_ai_Notion__notion-search`로 "드림플러스 investor club" 페이지를 찾는다.
   - 하위 항목(하위 페이지/블록) 중 **가장 최근 강연**을 찾는다 — 날짜가 있으면 그 기준으로, 없으면 페이지 목록상 최신 항목으로 판단한다. 애매하면 후보를 민소에게 보여주고 확인받는다.
   - `mcp__claude_ai_Notion__notion-fetch`로 해당 강연 페이지 전체를 읽는다.

2. **인사이트 추출**
   - 강연 전체를 요약 나열하지 않는다. 민소가 자기 판단에 실제로 쓸 수 있는 포인트 위주로 뽑는다 — 새로운 관점, 반박하고 싶은 주장, 더 확인해보고 싶어지는 지점.
   - **투자 조언을 생성하지 않는다** — 매수·매도 추천, 목표가, 기대수익률은 절대 쓰지 않는다. "이 강연이 말하는 것"과 "그게 왜 흥미로운가/왜 확인이 필요한가"까지만 다룬다.
   - 노션 원문에서 확인한 사실은 `[1차]`, 이 스킬이 추론·연결한 해석은 `[추정]`으로 반드시 구분한다. 라벨을 붙일 수 없는 주장은 쓰지 않는다.
   - 강연에서 다뤘지만 근거가 불충분하거나 애매한 수치·주장은 지어내지 말고 `unknown`으로 남긴다.

3. **파일로 저장**
   - `sources/dreamplus/` 폴더가 없으면 만든다.
   - 파일명: `{강연일자 또는 없으면 오늘 날짜}-{강연 제목(파일명에 안전하게 정리)}.md` — 예: `sources/dreamplus/2026-07-15-ai와-투자판단.md`
   - 아래 템플릿을 그대로 따른다.

## 출력 템플릿

```markdown
# {강연 제목}

## 강연 정보
- 일시: {날짜, 확인 안 되면 unknown}
- 출처: 노션 [드림플러스 investor club] — {페이지 URL}
- 정리일: {오늘 날짜}

## 핵심 내용 요약 [1차]
- {노션 원문에서 확인한 사실/주장만. 각 항목 끝에 [1차]}

## 인사이트 [추정]
- {민소의 판단에 쓸 수 있는 해석/연결. 왜 이게 중요한지 한 줄 이유 포함. 각 항목 끝에 [추정]}

## 확인 필요
- {애매하거나 근거 불충분해서 unknown으로 남긴 것들 — 무엇을, 어떻게 확인할지 제안}
```

## 규칙

- 완성된 파일 경로를 민소에게 알려주고, 저장 후 `git status`로 새 파일이 잡혔는지 보여준다 (커밋은 하지 않는다 — 커밋 여부는 민소가 결정).
- 노션 페이지를 못 찾거나 접근 권한이 없으면 추측해서 만들지 말고 검색 결과를 그대로 보여주며 어느 페이지인지 확인받는다.
- 강연이 여러 개 있고 "최신"이 모호하면(같은 날짜 여러 개 등) 후보 목록을 보여주고 선택받는다.
