# Macro Check — 거시지표 일일 점검

매일 시장 감을 잃지 않기 위해, 정해진 소스에서 금리·환율·주요지수·원자재를 가져와 `outputs/`에 그대로 기록한다. **소스는 아래 표로 고정** — 다른 사이트를 임의로 검색하거나 소스를 바꾸지 않는다. 소스 확장은 참가자가 명시적으로 요청할 때만.

## 소스 (고정)

모두 `curl -sL -A "Mozilla/5.0" <URL> | iconv -f euc-kr -t utf-8`로 접근한다 (Naver 페이지는 EUC-KR 인코딩). `WebFetch`는 `finance.naver.com`에서 차단되므로 쓰지 않는다.

| 지표 | URL | 값 위치 |
|---|---|---|
| 원/달러 환율 | `https://finance.naver.com/marketindex/` | "환전 고시 환율" 섹션, `id="exchangeList"` 내 첫 번째 `<span class="value">` (USD/KRW) |
| 원자재(유가·금시세) | `https://finance.naver.com/marketindex/` | 같은 페이지 "유가·금시세" 섹션 |
| 코스피 | `https://finance.naver.com/sise/sise_index.naver?code=KOSPI` | `<em id="now_value">` |
| 나스닥 종합·S&P500 | `https://finance.naver.com/world/` | 페이지에 내장된 JS 변수 `americaData` (JSON) 중 `NAS@IXIC`(나스닥종합)·`SPI@SPX`(S&P500)의 `last`(값)·`rate`(등락률)·`lastUpdTime` |
| 시장금리(국고채 3년) | `https://finance.naver.com/marketindex/interestDetail.naver?marketindexCd=IRR_GOVT03Y` | `class="no_today"` 근처 값 |
| 기준금리(한국은행) | `https://www.bok.or.kr/portal/main/contents.do?menuNo=200643` | 페이지 내 발표문/표 — 회의 때만 바뀌므로 직전 기록값과 비교해 "변동 없음" 또는 "변경됨(신규값)"으로 표시 |

## 절차

1. 오늘 날짜로 `outputs/<오늘 날짜>_거시지표.md` 파일이 이미 있으면, **조용히 건너뛰고 "오늘은 이미 기록됨"으로만 보고한다** — 덮어쓸지 되묻지 않는다. `/loop`나 스케줄러로 무인 실행될 수 있으므로, 확인 질문으로 자동 실행을 막지 않기 위함이다. (참가자가 대화 중에 명시적으로 "다시 받아와" / "덮어써"라고 하면 그때는 다시 가져와 덮어쓴다.)
2. 없으면 위 표의 6개 소스를 각각 curl로 가져와 값을 추출한다.
3. 항목별로 실패(HTTP 오류, 페이지 구조 변경으로 값을 못 찾음)하면 그 항목만 `unknown`으로 적고 실패 사유를 짧게 남긴다. **이전 값 재사용 금지, 임의 수치 생성 금지.**
4. 라벨: 소스 원자료를 그대로 가져온 값은 `[1차]`. 페이지에 해설·요약이 섞여 있고 그걸 인용한 경우만 `[2차]`. 숫자에 대한 해석·전망·매수매도 의견은 절대 쓰지 않는다 — 숫자와 출처만 기록한다.
5. 기준금리는 직전 `outputs/*_거시지표.md` 파일이 있으면 그 값과 비교해 "변동 없음" 또는 "변경됨"을 함께 적는다. 비교할 이전 파일이 없으면 비교 없이 값만 적는다.
6. `outputs/<오늘 날짜>_거시지표.md`로 저장한다:

   ```markdown
   # 거시지표 일일점검 — {날짜}

   - 날짜: {날짜}
   - 목적: 시장 감 유지 (context.md 결정 규칙 참조)

   ## 금리
   - 기준금리(한국은행): {값 또는 unknown} [1차] (출처: {URL}) — {변동 없음/변경됨/비교 불가}
   - 국고채 3년: {값}% [1차] (출처: {URL})

   ## 환율
   - 원/달러: {값} [1차] (출처: 네이버금융 환율)

   ## 주요 지수
   - 코스피: {값} ({등락률}) [1차]
   - 나스닥 종합: {값} ({등락률}) [1차]
   - S&P500: {값} ({등락률}) [1차]

   ## 원자재
   - WTI 유가: {값} [1차] (출처: 네이버금융 유가·금시세)
   - 국제 금시세: {값} [1차] (출처: 네이버금융 유가·금시세)

   ---
   가져오지 못한 항목: {목록 또는 없음}
   ```
7. 끝나면 저장된 파일 경로와, 값을 못 가져온 항목(`unknown`) 목록을 보고한다.

## 규칙

- 소스는 위 표에 고정된 것만 사용한다. 스킬이 임의로 다른 사이트를 검색하지 않는다.
- 투자 조언·해석·전망 문구를 생성하지 않는다 (CLAUDE.md 절대 규칙 1) — 숫자와 출처만.
- 확인 불가한 값은 `unknown`으로 적고 실패 사유를 남긴다. 이전 값이나 임의 수치로 채우지 않는다 (CLAUDE.md 절대 규칙 2).
- 모든 수치에 `[1차]`/`[2차]` 라벨을 붙인다 (CLAUDE.md 절대 규칙 3).
- 오늘자 파일이 이미 있으면 되묻지 않고 건너뛴다 — 무인 자동 실행(`/loop`, 스케줄러)을 전제로 한 설계.
