# industry-map — 산업 진입 첫 지도

> 내 병목: 리서치를 봐도 다음에 무엇을 볼지가 안 정해지는 내 막막함

## 절차

1. 산업 이름 하나를 확인한다 (예: "PE/M&A", "이차전지 소재").
2. 아래 고정틀 네 칸을 채운다. 수치·핵심 주장에는 CLAUDE.md 규칙대로 `[1차]`/`[2차]`/`[추정]` 라벨을 붙인다. 확인 불가하면 라벨 대신 `unknown`으로 쓰고 확인 방법을 제안한다.

   - **밸류체인 1장**: 이 산업에서 돈이 어디서 시작해 어디로 흘러가는지 한 장으로 (단계별 나열이면 충분하다)
   - **플레이어 5개**: 밸류체인 각 단계를 대표하는 회사·기관 5개, 각각 어느 단계에 있는지
   - **돈이 흐르는 지점 3개**: 실제로 돈이 오가는 접점 3개 (수수료/매출/투자금 등 — 무엇이 어디서 어디로)
   - **다음에 파볼 것 1개**: 지도를 그리면서 제일 안 풀린 지점 — 다음 세션에 깊이 볼 것 하나

3. 투자 조언(매수·매도·목표가·기대수익률)은 만들지 않는다 — 구조를 그리는 것까지가 이 스킬의 역할이다 (CLAUDE.md 절대 규칙).
4. 완성되면 참가자에게 그대로 보여주고 확인시킨다. 원하면 `context.md`의 "지금 보고 있는 것" 표와 "다음 소스 액션"에 반영한다 (참가자 동의 후).

## 규칙

- 산업 전체를 다 채우려 하지 않는다 — 고정틀 네 칸이 "완료"의 기준이다.
- 출처 라벨 없는 수치는 산출물에 쓰지 않는다.
- 이 스킬은 판단(매수/매도)을 대신하지 않는다. 구조와 다음 확인 지점만 정리한다.
