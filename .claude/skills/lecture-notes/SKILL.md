# 강의노트 — 강연 대본 → 누적 정리 문서

## 언제, 무엇을 다루는가

소유자는 강연을 녹음앱으로 녹음하고, 앱이 만들어준 대본(텍스트)을 직접 복사해서 대화에 붙여넣는다. 이 스킬은 오디오 파일 자체를 다루지 않는다 — Claude Code는 오디오를 들을 수 없으므로, 입력은 항상 소유자가 붙여넣은 텍스트다. mp3/m4a 파일이 폴더에 보여도 그 파일을 열려고 하지 않는다.

## 절차

1. 소유자가 붙여넣은 대본 텍스트를 받는다. 날짜나 강의명/주제가 대본에서 바로 안 보이면 짧게 물어본다.
2. 대본을 읽고 다음을 뽑아낸다:
   - **요약**: 2~4문장.
   - **핵심 주장**: 대본에 나온 구체적 주장·수치를 나열하고, 각 항목에 CLAUDE.md 절대 규칙 3(출처 라벨: `[1차]`/`[2차]`/`[추정]`)을 그대로 적용한다. 라벨은 세 가지뿐이다 — 새 라벨을 만들지 않는다.
     - 화자가 자신의 경험·지식·설명으로 직접 말한 내용이다 → `[1차]` (소유자가 직접 들은 강연 자체가 1차 자료)
     - 화자가 특정 보고서·공시·통계 등 외부 자료를 인용했다 → `[2차]` (인용된 원문은 아직 미확인)
     - 화자가 근거 제시 없이 던진 전망·수치다 → `[추정]`. 라벨조차 애매하면 `unknown`으로 남기고 확인 방법을 제안한다
   - **내 방향과의 연결**: `journey.md`의 "나의 선언"을 읽고 이 강연이 그 방향과 어떻게 이어지는지 한 줄로 적는다. 억지로 끼워 맞추지 않는다 — 관련이 안 보이면 "연결 없음"이라고 그대로 적는다.
3. `lecture-notes/lecture-notes.md`가 없으면 헤더만 있는 문서로 새로 만든다. 있으면 문서 맨 아래에 새 항목을 추가한다 (기존 내용을 지우거나 다시 쓰지 않는다):

   ```markdown
   ## {날짜} — {강의명/주제}

   **요약**: {요약}

   **핵심 주장**:
   - {주장 1} [라벨]
   - {주장 2} [라벨]

   **내 방향과의 연결**: {한 줄}

   **원본 대본**: `lecture-notes/raw/{날짜}-{강의명}.txt`
   ```

4. 붙여넣어진 대본 원문 전체를 `lecture-notes/raw/{날짜}-{강의명}.txt`에 그대로 저장한다 (나중에 소유자가 원문을 다시 확인할 수 있도록).
5. `lecture-notes/` 폴더를 이번에 처음 만들었다면, `journey.md`의 "내가 지은 방들" 섹션에 한 줄 남긴다:
   ```
   - {날짜}: lecture-notes/ 폴더를 지었다 (강연 대본 자동 정리)
   ```

## 규칙

- 대본에 없는 수치나 주장을 만들어내지 않는다. 애매하면 unknown으로 남기고 확인 방법을 제안한다.
- 이 스킬은 투자 판단을 대신하지 않는다 — 강연 내용을 정리·라벨링만 한다. 매수·매도·목표가 관련 발언이 있어도 그대로 인용·라벨링할 뿐 AI가 판단을 더하지 않는다.
- 기존 `lecture-notes.md` 내용은 절대 덮어쓰지 않는다 — 항상 맨 아래에 추가한다.
