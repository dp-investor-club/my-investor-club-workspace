# Lecture Notes — Google Docs → outputs/

참가자가 강연마다 Google Docs에 실시간으로 적어둔 노트를, 각 강연 도착 시점마다 별도 문서로 `outputs/`에 그대로 옮긴다. **요약·재구성 없이 원문 그대로.**

## 절차

1. 참가자가 준 Google Docs 공유 링크에서 문서 ID를 추출한다 (`/d/<ID>/` 패턴).
2. 원문을 그대로 받아온다:
   ```
   curl -sL "https://docs.google.com/document/d/<ID>/export?format=txt"
   ```
   공유 설정이 "링크가 있는 사람에게 공개"가 아니면 빈 응답이거나 로그인 페이지가 온다 — 이 경우 실패를 그대로 알리고 참가자에게 공유 설정 확인을 요청한다. 임의로 다른 값을 채워 넣지 않는다.
3. 받아온 텍스트의 첫 줄이 강연자·소속처럼 보이면 그것을 제목으로 삼는다. 첫 줄이 곧바로 내용(예: 개념·수치 나열)으로 시작해 강연자를 특정할 수 없으면, 임의로 지어내지 말고 참가자에게 강연자 이름을 물어본다.
4. `outputs/<오늘 날짜>_<제목 슬러그>.md` 로 저장한다. 슬러그는 공백을 `-`로 바꾸고 특수문자를 제거한다. 맨 위에 메타데이터를 붙인다:
   ```markdown
   # {제목}

   - 날짜: {오늘 날짜}
   - 출처: [1차] 강연 실시간 노트 (Google Docs 원본: {공유 링크})

   ---

   {원문 그대로}
   ```
5. 링크가 여러 개면 각각 반복한다.
6. 끝나면 생성된 파일 경로 목록을 보고한다.

## 규칙

- 원문을 요약·재구성하지 않는다 — "그대로 옮긴다"는 참가자의 요청을 지킨다.
- 출처 라벨은 항상 `[1차]`로 붙인다 (참가자 본인이 강연 중 실시간으로 작성한 1차 기록이므로).
- 이미 같은 날짜·제목의 파일이 있으면 덮어쓰기 전에 참가자에게 확인한다.
