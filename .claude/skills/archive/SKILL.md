# Archive — 이번 주 강의 자료를 outputs로

참가자가 매주 강의를 듣고 Google Drive에 올리는 녹음·정리본을, 이 레포의 `outputs/week-0N-archive.md`에 쌓는 스킬이다. 클럽이 주는 `club-archive`(클럽 공식 강의 원본)와는 반대 방향 — 이건 **참가자 본인이 만든 자료**를 담는다.

## 절차

### 1. 주차 확인
사용자가 주차를 말하지 않으면 `journey.md`의 "나의 진행 상태" 표를 보고 가장 최근 주차를 추정한 뒤 확인받는다. 짐작으로 파일명을 정하지 않는다.

### 2. Drive에서 자료 찾기
- 사용자가 링크를 줬으면 그 링크를 그대로 쓴다.
- 링크 없이 "이번 주 자료 정리해줘"라고만 했다면 `mcp__claude_ai_Google_Drive__search_files`로 주차/날짜 키워드를 넣어 찾고, 후보를 사용자에게 보여준 뒤 확인받는다 — 고정 폴더가 없으므로 잘못된 파일을 집을 수 있다.
- 파일마다 성격을 구분한다:
  - **정리본** (Google Docs, txt 등 텍스트류): `mcp__claude_ai_Google_Drive__read_file_content`로 본문을 가져온다.
  - **녹음** (mp3/m4a 등 오디오): 이 환경엔 전사(듣고 글로 바꾸는) 도구가 없다. `mcp__claude_ai_Google_Drive__get_file_metadata`로 파일명·링크만 확보하고, 내용을 절대 추측해서 채우지 않는다.

### 3. `outputs/week-0N-archive.md` 작성
파일이 이미 있으면 덮어쓰기 전에 사용자에게 보여주고 이어붙일지 새로 쓸지 확인한다. 없으면 아래 틀로 새로 만든다:

```markdown
# Week 0N Archive

## 정리본 원문
{정리본 텍스트 — 너무 길면 발췌하고 "전문은 원본 링크 참고"라고 표시}

## 핵심 요약
- 주장: ...
- 근거: ... [1차]/[2차]/[추정]
- unknown: 확인 안 된 것과 확인 방법

## 녹음
- {파일명}: {Drive 링크} (전사 안 됨 — 필요하면 아래 "막힐 때" 참고)
```

수치나 핵심 주장에는 `CLAUDE.md`의 라벨 규칙(`[1차]`/`[2차]`/`[추정]`)을 붙인다. 라벨을 붙일 수 없으면 그 주장은 쓰지 않는다.

### 4. 완료 후
`journey.md`의 "내가 지은 방들" 섹션에 이번에 자료를 축적했다는 한 줄을 남길지 물어본다 (강제하지 않는다).

## 원칙

- **정리본이 우선이다.** 녹음은 참고 링크일 뿐 — 이 스킬은 오디오 내용을 절대 지어내지 않는다.
- **투자 조언 금지.** 정리본 내용에 종목·매수매도·목표가가 있어도 그대로 인용만 하고, AI가 판단을 얹지 않는다.
- **크레덴셜 커밋 금지.** Drive 링크(URL)만 저장하고, 서비스 계정 키나 access token은 어떤 파일에도 쓰지 않는다.
- **참가자 소유.** `outputs/`는 참가자의 판단 자산이다 — 요약 문구가 마음에 안 들면 참가자 말대로 고친다.

## 막힐 때 — 녹음 전사가 필요하면

지금은 로컬에 전사 도구가 없어 링크만 남긴다. 자동 전사를 원하면:
```bash
brew install ffmpeg
pip install openai-whisper
```
설치 후엔 `whisper <다운로드한 오디오 파일>`로 텍스트 변환이 가능하다 (API key 불필요, 완전 로컬). 이 스킬은 아직 이 단계를 자동 실행하지 않는다 — 설치 여부를 먼저 사용자에게 확인한 뒤 다음 개선에서 붙인다.
