# /뉴스 — 오늘 볼 3개 + 크립토 1줄

> 내 병목: **매일 경제뉴스를 열 시간도, 뭘 볼지도 정해져 있지 않은 내 막막함**

**설계 원칙: 매번 검색하지 않는다.** 검색하면 매일 결과가 들쭉날쭉하고, 그게 "뭘 볼지 모르겠다"의 원인이다. 이 스킬은 **아래 고정 소스 목록을 매일 그대로 연다.** 기존 브리핑 서비스들이 하는 일이 그것이다.

## 입력

없다. `/뉴스`만 치면 된다. (`/뉴스 반도체`처럼 축을 좁힐 수 있다)

## 끝나면 남는 것

- 화면에 **오늘 볼 3개 + 크립토 1줄**, 각각 한 줄 요약과 출처 라벨
- `news-log.md` 맨 아래에 오늘 날짜로 append (기존 내용 수정 금지)

## 실행 순서

### 1. 지수 한 줄 (증권사 모닝브리프 방식)
3층에서 종가/현재가를 가져와 한 줄로. 확인 안 되는 값은 지어내지 말고 `unknown`.

### 2. 1층부터 연다 — 오늘 발표된 것이 최우선
경제지표 캘린더로 **오늘 뭐가 발표되는지** 먼저 본다. 발표가 있으면 그것이 1번 항목이다. 발표 원문이 아직 안 나왔으면 "오늘 나온다 + 수치는 unknown"으로 적고 확인할 URL을 남긴다.

### 3. 3개로 자른다 — 축이 겹치면 버린다
축: **국내 거시 / 글로벌 금융 / 테크**. 세 개가 같은 얘기면 하나로 합치고 빈 축을 채운다. 3개보다 많이 주지 않는다 — 많으면 안 보게 되고, 그게 원래 병목이다.

### 4. 크립토 1줄 (순살 방식 — 별도 섹션)
비트코인 가격 + 오늘 크립토 축에서 실제로 일어난 사건 하나. 없으면 "특이사항 없음"으로 한 줄.

### 5. 형식 — 터미널이 아니라 **한 페이지로 뽑는다**

터미널에 텍스트를 쏟으면 안 읽는다. HTML 한 장으로 만들어 `Artifact`로 발행한다 (아침에 폰으로 여는 것이 기본 사용처). 페이지 순서는 고정:

```
[헤더]  장전 브리핑 · 날짜
[지수 테이프]  코스피 · 나스닥 · 달러/원 · 유가 · BTC   ← unknown은 회색 이탤릭으로 그대로 표시
[1][2][3]  각 카드: 축 라벨 → 제목(기사 원문 하이퍼링크) → "왜 지금" 배경 한 줄
           → 인사이트 블록 [추정] → 출처 라벨+링크 → 용어 토글
[크립토]   별도 색 블록 (순살 방식 2단 분리)
[내 판단이 바뀌는 지점]  점선 박스 한 줄
[푸터]   오늘 연 소스 / 못 연 구멍 / 조언 아님 고지
```

**하이퍼링크 (필수)** — 제목을 누르면 **기사 본문**으로 간다. 섹션 페이지·RSS 주소를 링크로 걸지 않는다. RSS를 열 때 `<link>` URL을 함께 받아와 그 주소를 쓴다. 가능하면 `[1차]` 원문(한은 보도자료, ECB 결정문, 기업 IR) 링크를 하나 더 나란히 건다. 모든 외부 링크는 `target="_blank" rel="noopener"`.

**인사이트 블록 (필수, 접힌 토글)** — 항목 1·2·3 각각에 `[추정]` 라벨을 단 인사이트 토글을 넣는다. **기본값은 닫힘.** 펼치기 전 화면에는 사실(제목·왜 지금·출처)만 남고, 해석은 열어야 나온다 — 사실과 해석이 섞이지 않게 하는 장치이자, 10분 브리핑을 지키는 장치다. 접힘 상태의 요약줄에 `기다릴 것 N · 오늘 할 것 N`을 표시해 안에 뭐가 있는지 알 수 있게 한다.

내용은 세 줄 구성:
1. **이 뉴스가 오늘 어떻게 읽히는가** — 다른 항목·지수와 이어붙인 해석
2. **무엇과 연결되는가** — 테이프의 숫자나 다른 항목과의 연결 (확인 안 된 부분은 `unknown` + 확인처)
3. **놓치기 쉬운 지점** — 이 숫자를 오독하게 만드는 함정

그리고 **so what 두 종류를 반드시 붙인다** — 해석에서 끝나면 브리핑이 아니라 감상이다.

| 칩 | 무엇을 쓰나 |
|---|---|
| `기다릴 것` | **다음에 무엇이 나오면 이 이야기가 갈리는가** + 그 시점. 1~2개. 날짜를 모르면 `unknown`으로 적고 **어디서 확인하는지**를 함께 쓴다. "지켜보자"로 끝내지 않는다 — 갈림길을 명시한다. |
| `오늘 할 것` | **오늘 10분 안에 끝나는 확인 행동 하나.** 어떤 자료의 어떤 숫자를 뽑을지까지 구체적으로. 소요 시간을 괄호로 적는다. 못 찾으면 `unknown`으로 적고 넘어가라고 명시한다. |

`오늘 할 것`은 **확인·기록 행동만** 쓴다. 매매·비중 조절은 어떤 형태로도 쓰지 않는다.

인사이트는 **해석이지 조언이 아니다.** 매수·매도·목표가는 어떤 형태로도 쓰지 않는다. 푸터에 "인사이트는 추정" 고지를 남긴다.

**용어 토글 (필수)** — 지수 테이프와 항목 1·2·3, 크립토, 판단 줄에 각각 접힌 `<details>` 토글을 단다. 기본은 접힘 — **10분 브리핑을 방해하지 않고, 모르는 단어가 나온 사람만 편다.**
- 토글 안은 `용어 → 한 줄 정의 → 그래서 오늘 이 뉴스에서 왜 중요한가` 순서. 3~5개.
- 정의는 쉬운 말로. "전분기 대비인가 전년 대비인가", "예상치는 누구 것인가"처럼 **숫자를 오독하게 만드는 지점**을 우선한다.
- 토글 안에서도 확인 안 된 것은 `unknown`으로 적는다. 추측으로 메우지 않는다.
- 조언은 넣지 않는다. 판단 줄의 토글은 "이 줄은 사라/팔라가 아니다"를 명시한다.

규칙:
- 제목·요약은 **무슨 일이 있었는지**만. 전망·해석·"~할 것으로 보인다"는 쓰지 않는다.
- `[1차]`는 진한 라벨, `[2차]`는 테두리만 — **확인된 것과 아직 아닌 것이 스크롤 없이 갈려야 한다.**
- 못 연 소스·확인 실패는 푸터의 "구멍"에 **반드시 적는다.** 조용히 넘어가면 다음날 같은 구멍이 반복된다.
- 라이트/다크 둘 다 대응. 발행 후 URL을 참가자에게 준다.

### 6. 파일에 남긴다
`news-log.md` 맨 아래에 `## YYYY-MM-DD`로 append.

### 7. 닫는 한 줄
**"셋 중 더 파볼 게 있나요? 없으면 오늘은 끝."**
있으면 그 항목만 `context.md`의 "다음 소스 액션"에 append. 없으면 끝낸다 — **끝내는 게 기본값이다.**

## 금지

- 종목 추천·매수/매도·목표가·기대수익률 생성 금지. 이 스킬은 **뭘 볼지 정해주는 스킬**이지 판단해주는 스킬이 아니다.
- 확인 안 된 수치를 지어내지 않는다. 확인 불가면 `unknown` + 확인 방법 한 줄.
- 3개보다 많이 주지 않는다. 길게 쓰지 않는다.
