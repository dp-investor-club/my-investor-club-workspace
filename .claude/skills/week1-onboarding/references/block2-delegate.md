# Block 2: 위임 — 첫 방 짓기

## EXPLAIN

**수업 복습**: "이제 경쟁력은 '얼마나 잘 하는가'가 아니라 '무엇을 시킬 것인가'입니다. 맥락을 정의하고, 기준을 세우고, 결과를 검증하는 사람."

위임의 3박자: **말했다 → 됐다 → 확인했다.** 지금 그걸 처음부터 끝까지 해본다. 대상은 진짜 필요한 것 — **오늘 들은 1주차 자료를 내 언어로 옮기는 일**이다.

이 작업실에는 주차축이 **둘** 있다:

| 폴더 | 누구 것 | 무엇이 |
|---|---|---|
| `club/week-0N/` | 클럽 (읽기전용) | 자료 원본 — 이미 들어 있다 |
| `weeks/week-0N/` | **나** | 내 언어로 다시 쓴 것 |

원본은 이미 있으니 만들 필요가 없다. **원본을 내 언어로 바꾸는 일**을 AI에게 시킨다.

## EXECUTE

아래 문장을 **직접 입력**한다 (AI가 대신 만들어주지 않는다 — 첫 위임 경험이 목적):

```
club/week-01/ 에 뭐가 있는지 보여주고, 그중 sources/ 개념 카드를 읽어서
내가 오늘 처음 들은 개념 5개를 골라 weeks/week-01/개념정리.md 에 내 말로 정리해줘.
원본을 복사하지 말고, 내가 나중에 읽어서 이해할 수 있는 문장으로 써줘.
```

끝나면 확인한다: `weeks/week-01/개념정리.md 보여줘`

## QUIZ / 스캐폴드 확인

[스캐폴드] `weeks/week-01/개념정리.md`가 생겼는지 확인시키고, 두 폴더 규칙 한 문장: **"`club/`은 클럽이 채우고 여러분은 읽습니다. `weeks/`는 여러분이 채웁니다 — 원본을 복사하지 말고 여러분 말로 다시 쓰세요. 그 차이가 여러분의 자산입니다."** 자료가 새로 올라오면 `/update`로 `club/`을 갱신한다는 것도 한 줄 알려준다.

퀴즈: "방금 위임에서 가장 중요한 마지막 단계는?"
- **결과를 내 눈으로 확인한 것** (정답 — 검증 없는 위임은 위임이 아니라 방치)
- 명령어를 정확히 외운 것 (외울 필요 없음)
- 빠르게 시킨 것 (속도는 부산물)

journey.md "내가 지은 방들"에 기록: "{날짜}: weeks/week-01에 내 개념정리를 지었다".
