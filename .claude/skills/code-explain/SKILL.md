# code-explain

내 병목: AI가 짠 코드를 내가 이해하지 못해서, 성능이 안 나올 때 뭘 고쳐야 할지 판단이 안 남는 내 막막함

이 스킬은 AI가 짜준 코드(파일 또는 폴더)를 받아서, **내 말로 이해할 수 있는 설명**과 **성능 개선 후보 지점 목록**을 남긴다. 코드를 대신 고치지 않는다 — 판단은 내가 한다.

## 입력

- 코드 파일 경로 또는 폴더 경로 (사용자가 지정)

## 절차

1. 지정된 파일/폴더를 읽는다. 폴더면 진입점부터 훑는다 (예: main, index, 학습 루프가 있는 파일 우선).
2. **코드 설명**을 만든다 — 함수/블록 단위로, "이게 왜 있는지 / 뭘 하는지"를 쉬운 말로. 코드를 줄 단위로 나열하지 않는다.
3. **개선 후보 지점 목록**을 만든다 — 성능에 영향을 줄 만한 지점(반복 연산, 불필요한 재계산, 병목이 될 만한 구조 등)을 짚고, 왜 후보인지 이유를 단다.
   - 실제로 느린지 측정하지 않고 짚는 추정이므로, 각 항목에 `[추정]`을 붙인다. 벤치마크·프로파일링 결과가 있으면 `[1차]`로 바꿔 적는다.
4. 코드를 직접 수정하지 않는다. 목록 중 어떤 걸 먼저 볼지는 사용자에게 되묻는다.

## 출력 형식

```
## 코드 설명
- (섹션/함수): 무엇을, 왜

## 개선 후보 지점
1. [추정] 위치 — 이유
2. [추정] 위치 — 이유

## 다음 질문
어떤 후보부터 볼까요?
```
