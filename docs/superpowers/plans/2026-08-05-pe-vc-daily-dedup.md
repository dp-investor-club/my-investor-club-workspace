# pe-vc-daily 매체 간 중복 딜 병합 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `peer-skills/peer-junha-pe-vc-daily/SKILL.md`에 매체 간 중복 딜 병합 절차를 추가해, 무인(스케줄) 실행에서도 같은 딜이 여러 매체에서 중복 항목으로 쌓이지 않게 한다.

**Architecture:** 이 작업은 애플리케이션 코드가 아니라 AI가 따르는 자연어 절차 문서(SKILL.md) 한 파일을 수정하는 것이다. 새 절차 단계를 기존 "본문 확인" 단계 바로 뒤에 끼워 넣고, 이후 단계(항목 추출·저장·웹페이지 생성)에서 "병합된 항목"을 어떻게 다루는지 각각 보강한다. 코드 테스트 대신, 각 수정 뒤 파일을 다시 읽어 번호·용어 일관성을 확인하고, 마지막 태스크에서 가상의 2-매체 중복 사례로 수동 드라이런을 한다.

**Tech Stack:** Markdown (SKILL.md) — 코드 없음.

## Global Constraints

- 투자 조언(매수·매도 추천, 목표가, 기대수익률)을 생성하지 않는다 — 기존 SKILL.md "하지 않는 것" 원칙, 이번 수정도 위반하지 않는다.
- 근거 없는 수치를 만들지 않는다. 확인 불가하면 `unknown`으로 남긴다 — 병합 시 매체 간 사실이 다를 때도 동일하게 적용.
- 노트 폴더는 `sources/pe-vc-daily/`에 고정하고 참가자에게 경로를 묻지 않는다 — 이번 수정에서 이 부분은 건드리지 않는다.
- 병합 기준은 보수적으로: 회사/펀드명 + 딜 유형 + 핵심 사실(금액·라운드·거래상대방) 중 하나 이상 일치, 셋 중 하나라도 불확실하면 병합하지 않는다 (spec 결정 사항, 그대로 유지).
