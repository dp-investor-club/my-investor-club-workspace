research

강연 전, 연사와 소속 House를 공개 정보로 사전조사한다.

어떤 병목

강연 전에 사전 배경 지식을 알면 더 좋은 질문을 하고, 더 좋은 인사이트를 얻을 수 있을 것 같아서 만들었다.

입력 → 남는 것

연사명과 연사가 속해있는 조직 혹은 House의 이름을 주면 → 개괄적인 리서치와 질문 후보가 남는다.

설치 후 첫 실행

"research 진행해줘. 이번 강연의 연사는 OO House의 OO이야."

아직 안 되는 것

아직 모름

출력 포맷 예시 (가상 데이터)

# OO벤처스 김OO — 사전 리서치

## 연사 프로필
- OO벤처스 파트너, 이전 OO증권 리서치센터 애널리스트 출신 [2차]
- 확인 안 된 부분: unknown — 회사 공식 프로필 페이지 확인 필요

## 소속 투자자 House 개요
- 2015년 설립, AUM 3천억원대, 초기~시리즈A 중심 [1차]

## 최근 딜소싱·포트폴리오
- 최근 2년간 헬스케어·기후테크 분야 8건 투자 [2차]

## 관련 기사·인터뷰
- [OO벤처스 김OO 인터뷰](https://example.com)

## 내가 물어볼 질문 후보
1. 초기~시리즈A 단계에서 가장 중요하게 보는 지표는 무엇인가요?
2. 헬스케어·기후테크를 동시에 보는 이유는 무엇인가요?
3. 최근 투자 결정에서 가장 어려웠던 판단은 무엇이었나요?

insights

강연 후, 그날 알게 된 것을 태그별로 압축해 기록한다.

어떤 병목

강연마다 쏟아지는 인사이트를 그때그때 적어두지 않으면 흩어져서 나중에 못 찾게 되는 문제를 풀려고 만들었다.

입력 → 남는 것

강연 후 "insights 정리해줘"라고 부르면(Notion 연동 시 자동, 아니면 되물어서) → 태그별로 묶인 insights.md 기록 한 줄이 남는다.

설치 후 첫 실행

"insights 정리해줘. 오늘 강연은 OO였어."

아직 안 되는 것

DREAMPLUS 세션 외(커피챗·콜드메일 등) 기록은 대상이 아님.

출력 포맷 예시 (가상 데이터)

- 2026-07-15 / 김OO(OO벤처스 파트너) — 초기 투자 라운드에서의 판단 기준
  - **#투자전략**: 하방 먼저 보기, 라운드별 소진율 점검, 후속투자 여력 확보
  - **#태도**: 질문 목록 미리 만들어가기, 모르는 용어 그 자리에서 확인
