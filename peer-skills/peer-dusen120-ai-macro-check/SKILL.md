## 이 스킬은
- 어떤 병목: 수치만 쌓여 있고 글로 정리가 안 남는 내 막막함
- 입력 → 남는 것: 고정 7개 소스(한국은행·네이버금융)에서 값을 받아 → `outputs/{날짜}_거시지표.md`로 남는다. 어제 대비 변화표와 3줄 요약이 파일 맨 위에 온다.
- 설치 후 첫 실행: "오늘 지표 보여줘"
- 아직 안 되는 것: 아직 모름

# Macro Check — 거시지표 일일 점검

매일 시장 감을 잃지 않기 위해, 정해진 소스에서 금리·환율·주요지수·원자재를 가져와 `outputs/`에 그대로 기록한다. **소스는 아래 표로 고정** — 다른 사이트를 임의로 검색하거나 소스를 바꾸지 않는다. 소스 확장은 참가자가 명시적으로 요청할 때만.

## 소스 (고정)

Naver 페이지는 `curl -sL -A "Mozilla/5.0" <URL> | iconv -f euc-kr -t utf-8`로 접근한다 (EUC-KR 인코딩). BOK 기준금리 페이지는 UTF-8이므로 `iconv` 없이 `curl -sL -A "Mozilla/5.0" <URL>` 그대로 쓴다. `WebFetch`는 `finance.naver.com`에서 차단되므로 쓰지 않는다.

| 지표 | URL | 값 위치 |
|---|---|---|
| 원/달러 환율 | `https://finance.naver.com/marketindex/` | "환전 고시 환율" 섹션, `id="exchangeList"` 내 첫 번째 `<span class="value">` (USD/KRW) |
| 원자재(유가·금시세) | `https://finance.naver.com/marketindex/` | 같은 페이지 "유가·금시세" 섹션 |

## 절차

1. 오늘 날짜로 `outputs/<오늘 날짜>_거시지표.md` 파일이 이미 있으면, **조용히 건너뛰고 "오늘은 이미 기록됨"으로만 보고한다** — 덮어쓸지 되묻지 않는다. `/loop`나 스케줄러로 무인 실행될 수 있으므로, 확인 질문으로 자동 실행을 막지 않기 위함이다. (참가자가 대화 중에 명시적으로 "다시 받아와" / "덮어써"라고 하면 그때는 다시 가져와 덮어쓴다.)
2. 없으면 위 표의 7개 소스를 각각 curl로 가져와 값을 추출한다.
3. 항목별로 실패(HTTP 오류, 페이지 구조 변경으로 값을 못 찾음)하면 그 항목만 `unknown`으로 적고 실패 사유를 짧게 남긴다. **이전 값 재사용 금지, 임의 수치 생성 금지.**
4. 라벨: 소스 원자료를 그대로 가져온 값은 `[1차]`. 페이지에 해설·요약이 섞여 있고 그걸 인용한 경우만 `[2차]`. 숫자에 대한 해석·전망·매수매도 의견은 절대 쓰지 않는다 — 숫자와 출처만 기록한다.
5. 기준금리는 직전 `outputs/*_거시지표.md` 파일이 있으면 그 값과 비교해 "변동 없음" 또는 "변경됨"을 함께 적는다. 비교할 이전 파일이 없으면 비교 없이 값만 적는다.
6. **어제 대비 변화 표 만들기**: `outputs/*_거시지표.md` 중 오늘 날짜가 아닌 파일들 중 파일명 날짜 기준 가장 최근 것을 찾는다(직전 기록). 있으면 그 파일에서 국고채 3년·원/달러·코스피·나스닥 종합·S&P500·WTI·국제 금시세 값을 파싱해 오늘 값과 비교하고, 지표별로 상승(🔺)·하락(🔻)·보합(➖)과 변화폭을 계산한다. 기준금리는 5번의 변동여부를 그대로 쓴다. 값을 못 가져와 `unknown`인 지표는 변화 계산 없이 `unknown`으로 표시한다. 직전 기록 파일이 아예 없으면 표 전체를 생략하고 "비교 대상 없음(첫 기록)"이라고 적는다.
6-1. **오늘 요약(3줄) 만들기**: 6번 표가 있을 때만 만든다(첫 기록이면 생략하고 "비교 대상 없음(첫 기록)"). 변화 표에 이미 있는 🔺/🔻/➖와 수치만 근거로, 그날 지표가 어떻게 움직였는지 **사실만** 3줄로 서술한다.
   - 각 줄은 표에 있는 값·방향을 그대로 옮겨 문장으로 만든다. 새 수치나 표에 없는 정보를 넣지 않는다.
   - **금지어**: 전망·예상·반등·조정·저점·고점·매수·매도·타이밍·좋다/나쁘다 등 해석·판단·투자의견으로 읽히는 표현 (CLAUDE.md 절대 규칙 1). "상승/하락/보합/동반/엇갈림"처럼 방향만 서술하는 동사만 쓴다.
   - 예시 톤: "코스피는 6,642.48로 전일 대비 398.08 하락, 나스닥·S&P500도 동반 하락했다.", "국고채 3년 금리는 3.95%로 0.04%p 상승했다.", "WTI 유가는 상승, 국제 금시세는 하락으로 원자재는 엇갈렸다."
   - 라벨은 표에서 이미 `[1차]`로 붙었으므로 요약 문장 자체에는 다시 붙이지 않되, 요약 아래에 "표의 [1차] 수치를 서술로 옮긴 것" 한 줄을 출처 고지로 남긴다.
7. `outputs/<오늘 날짜>_거시지표.md`로 저장한다. **어제 대비 변화 표와 오늘 요약(3줄)은 맨 위, 목적 바로 아래에 둔다** — 파일을 열자마자 한눈에 보이도록:

   ```markdown
   # 거시지표 일일점검 — {날짜}

   - 날짜: {날짜}
   - 목적: 시장 감 유지 (context.md 결정 규칙 참조)

   ## 어제 대비 변화 (vs {직전 기록 날짜})
   | 지표 | 오늘 | 직전 | 변화 |
   |---|---|---|---|
   | 기준금리 | {값} | {값} | {변동 없음/변경됨} |
   | 국고채 3년 | {값}% | {값}% | {🔺/🔻/➖} {차이}%p |
   | 원/달러 | {값} | {값} | {🔺/🔻/➖} {차이}원 |
   | 코스피 | {값} | {값} | {🔺/🔻/➖} {차이} |
   | 나스닥 종합 | {값} | {값} | {🔺/🔻/➖} {차이} |
   | S&P500 | {값} | {값} | {🔺/🔻/➖} {차이} |
   | WTI 유가 | {값} | {값} | {🔺/🔻/➖} {차이} |
   | 국제 금시세 | {값} | {값} | {🔺/🔻/➖} {차이} |

   (직전 기록 파일이 없으면 이 표 대신: "비교 대상 없음(첫 기록)")

   ## 오늘 요약 (3줄)
   - {위 표의 방향·수치만 근거로 한 사실 서술 1}
   - {사실 서술 2}
   - {사실 서술 3}
   (표의 [1차] 수치를 서술로 옮긴 것 — 해석·전망·투자의견 아님)
   (직전 기록 파일이 없으면 이 섹션 생략)

   ## 금리
   - 기준금리(한국은행): {값 또는 unknown} [1차] (출처: {URL}) — {변동 없음/변경됨/비교 불가}
   - 국고채 3년: {값}% [1차] (출처: {URL})

   ## 환율
   - 원/달러: {값} [1차] (출처: 네이버금융 환율)

   ## 주요 지수
   - 코스피: {값} ({등락률}) [1차]
   - 나스닥 종합: {값} ({등락률}) [1차]
   - S&P500: {값} ({등락률}) [1차]

   ## 원자재
   - WTI 유가: {값} [1차] (출처: 네이버금융 유가·금시세)
   - 국제 금시세: {값} [1차] (출처: 네이버금융 유가·금시세)

   ## 리서치 리포트 (네이버금융, {날짜} 기준)
   | 구분 | 대상 | 제목 | 증권사 | 작성일 | PDF |
   |---|---|---|---|---|---|
   | 종목분석 | {기업명} | {제목} | {증권사} | {작성일} | [링크]({PDF URL}) |
   | ... | | | | | |
   | 산업분석 | {산업명} | {제목} | {증권사} | {작성일} | [링크]({PDF URL}) |
   | ... | | | | | |

   (페이지에 나온 행을 모두 그대로 옮긴다 — 본문 요약·해석 없이 제목/증권사/링크만. 모든 행 `[1차]`. 페이지를 못 가져오면 이 섹션 전체를 생략하고 "가져오지 못한 항목"에 사유를 남긴다.)

   ---
   가져오지 못한 항목: {목록 또는 없음}
   ```
8. 끝나면 저장된 파일 경로와, 값을 못 가져온 항목(`unknown`) 목록을 보고한다.

## 규칙

- 소스는 위 표에 고정된 것만 사용한다. 스킬이 임의로 다른 사이트를 검색하지 않는다.
- 투자 조언·해석·전망 문구를 생성하지 않는다 (CLAUDE.md 절대 규칙 1) — 숫자와 출처만.
- 확인 불가한 값은 `unknown`으로 적고 실패 사유를 남긴다. 이전 값이나 임의 수치로 채우지 않는다 (CLAUDE.md 절대 규칙 2).
- 모든 수치에 `[1차]`/`[2차]` 라벨을 붙인다 (CLAUDE.md 절대 규칙 3).
- 오늘자 파일이 이미 있으면 되묻지 않고 건너뛴다 — 무인 자동 실행(`/loop`, 스케줄러)을 전제로 한 설계.
