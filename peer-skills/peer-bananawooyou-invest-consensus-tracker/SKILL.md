# consensus-tracker

여러 종목의 컨센서스를 지난주 대비 비교한 기록이 안 남는 내 막막함 — 이 병목을 풀기 위한 스킬.

"컨센서스 트래킹", "컨센서스 갱신", "이번 주 컨센서스", "consensus-tracker" 요청에 사용.

## 무엇을 하는가

context.md의 유니버스(종목 목록)를 기준으로, **컴퍼니가이드(comp.fnguide.com / wcomp.fnguide.com)의 집계 컨센서스** 수치(매출액, 영업이익)를 매주 `data/consensus_log.csv`에 누적 기록하고, 지난 주 대비 변동폭을 표 + 차트(Artifact)로 보여준다.

증권사 하우스별 개별 추정치(리포트 한 건 단위)는 이 스킬의 대상이 아니다 — 컴퍼니가이드가 여러 추정기관을 이미 집계해 놓은 숫자 하나를 기준으로 삼는다.

## 절차

1. **유니버스 확인**: context.md의 "지금 보고 있는 것" 표에서 종목 리스트를 읽고, 각 종목의 KRX 종목코드를 확인한다 (모르면 `mcp__asset-management__find_ticker`로 조회).
   - 참가자가 **유니버스에 없는 기업**을 말하면, 조회 전에 먼저 "이 기업을 유니버스에 추가할까요?"라고 확인한다.
     - 승인 → context.md 유니버스에 추가한 뒤 2번부터 진행. 이후 로그(`data/consensus_log.csv`)에 남아 다음 주부터 변동폭 비교가 가능하다.
     - 거절 → 그래도 2번부터 조회는 진행하되(일회성), **로그에는 append하지 않는다** — 유니버스에 없으니 지난 기록이 없고, 이번 조회도 다음 주 비교 대상으로 남지 않는다는 점을 결과와 함께 알려준다.
2. **컴퍼니가이드 접속**: Chrome 브라우저 도구로 `https://wcomp.fnguide.com/`에 접속 → 검색창에 종목코드 입력 → 드롭다운에서 해당 종목 클릭한다 (URL을 직접 조립하면 리다이렉트로 실패할 수 있으니 검색 흐름을 따른다).
3. **페이지 텍스트 추출**: 종목 페이지가 뜨면 `mcp__claude-in-chrome__get_page_text`로 페이지 전체 텍스트를 한 번에 가져온다. **스크롤·스크린샷으로 표를 찾지 않는다** — `get_page_text`가 Financial Highlight 표를 포함한 전체 텍스트를 한 번에 반환하므로 그 결과에서 바로 파싱한다 (스크린샷 방식보다 훨씬 빠르다). WebFetch는 이 페이지가 JS로 렌더링돼 표 내용을 못 읽으므로 쓰지 않는다.
4. **Financial Highlight 표에서 컨센서스 추출**: 추출한 텍스트에서 "Financial Highlight" 표를 찾아 **(E)/(P) 표시가 붙은 컬럼** (당해 연도 연간 컨센서스 + 최근 분기 컨센서스)의 "매출액"과 "영업이익(발표기준)" 행 값을 그대로 가져온다. 단위는 억원.
5. **로그에 append**: 유니버스 종목(1번에서 추가 승인한 경우 포함)만 `data/consensus_log.csv`에 아래 컬럼으로 한 줄씩 추가한다 (기존 행 수정 금지, append만). 일회성 조회(1번에서 추가를 거절한 경우)는 이 단계를 건너뛴다.
   ```
   date,ticker,period,metric,value_억원,label,source
   ```
   `date`는 조회일, `period`는 컨센서스가 걸린 회계기간(예: `2026/12(E)`, `2026/06(E)`), `label`은 `추정` 고정, `source`는 `FnGuide 컴퍼니가이드 컨센서스(집계)`.
6. **변동폭 계산**: 같은 종목·같은 period·같은 metric의 직전 기록과 이번 기록을 비교해 Δ(절대값, %)를 계산한다. 직전 기록이 없으면 "이번이 첫 기록"이라고 표시한다. 일회성 조회는 애초에 로그가 없으므로 Δ 계산 없이 이번 조회값만 보여준다.
7. **표 + 차트로 출력**: 표(종목/period/지표/지난주/이번주/Δ)로 먼저 보여주고, Artifact(dataviz 스킬 참고)로 종목별 추이 라인 차트를 만든다.
8. **결과를 context.md에 반영하지 않는다** — 이 스킬은 로그(data/consensus_log.csv)에만 쓴다. context.md 갱신은 source-watch의 역할.

## 규칙

- 종목추천·목표가 판단·매수매도 의견 생성 금지. 수치 비교와 시각화만 한다.
- 라벨 없는 수치는 기록하지 않는다.
- 로그 파일은 append-only. 과거 행을 고치지 않는다 — 잘못된 값이 있으면 정정 행을 새로 추가한다.
