# Market Map

**첫 실행**: `/market-map` (outputs/market-notes/overview.md가 없으면 신규 모드로 전체 개요부터 시작된다)

## 실행 방식

### 1. 입력 확인
`outputs/market-notes/overview.md`가 없으면 **신규 모드**(개요부터 작성), 있으면 **갱신 모드**(이슈만 추가, 개요는 요청 시에만 갱신)로 들어간다. 특정 종목/자산군 하나만 콕 집어 물어보면 그 범위만 처리한다.

### 2. 개요 작성 (신규 모드, 또는 갱신 요청 시)

26종목 각각에 대해 아래를 채운다. 확인 불가한 항목은 `[1차]`/`[2차]`/`[추정]` 라벨과 함께, 정 안 되면 `unknown`으로 남긴다 — 지어내지 않는다.

- **무엇을 추종하는가** — 기초지수/기초자산 (예: PLUS 200 → 코스피200)
- **패시브/액티브, 실물/선물/합성 구분** — 종목명에 이미 드러난 것도 출처로 재확인
- **환헤지 여부** — 이름에 `(H)`/`합성H`가 있으면 헤지형, 없으면 언헤지로 확인
- **자산군 내 성격** — 예: 채권이면 만기(단기/장기), 국채/회사채, 국내/해외 발행 구분. 원자재면 귀금속/에너지/농산물/산업금속 구분

자산군별로 5개 그룹(국내주식/해외주식/채권/원자재/리츠)의 특징을 몇 문장으로 요약한다. **배분 비율은 제안하지 않는다** — 각 자산군·종목이 뭘 담고 있는지까지만 정리하고, 얼마나 담을지는 참가자가 정한다.

### 3. 이슈 업데이트 — "오늘 왜 움직였는지" 중심

**당일성 이슈**가 기본 축이다 (`industry-study`의 당일성 이슈 방식을 그대로 가져온다):
- 당일 뉴스·속보 `[2차]`
- 거시 지표 발표(금리·환율·유가 등) `[1차]`
- **같은 자산군 내 다른 종목도 같이 움직였는지** — 자산군 전체가 움직인 건지 개별 종목만의 이슈인지 반드시 구분한다
- **자산군 간 반대 방향으로 움직였는지** — 관찰해서 기록만 하고, 분산이 "잘 되고 있다/아니다" 같은 판단은 AI가 내리지 않는다

CLAUDE.md 절대 규칙을 그대로 따른다: 모든 수치·핵심 주장에 라벨을 붙이고, 확인 불가한 수치는 `unknown`으로 남기며, 매수·매도 추천이나 목표가·배분 비율은 생성하지 않는다.

새로 확인된 이슈만 이슈 로그에 날짜순으로 추가한다. 기존 로그는 건드리지 않는다.

### 4. 저장 템플릿

`outputs/market-notes/overview.md`:

```markdown
# 모의투자 유니버스 — 시장 지도

- 마지막 갱신: YYYY-MM-DD

## 자산군별 개요

### 국내 주식
| 종목명 | 코드 | 추종 대상 | 패시브/액티브 | 비고 |
|---|---|---|---|---|
| ... | ... | ... | ... | ... |

### 해외 주식
(위와 같은 표 형식 — 선진국/신흥국 구분 포함)

### 채권
(위와 같은 표 형식 — 만기·국채/회사채·국내/해외 구분 포함)

### 원자재
(위와 같은 표 형식 — 귀금속/에너지/농산물/산업금속 구분 포함)

### 리츠
(위와 같은 표 형식)

## 이슈 로그 (최신순)

### YYYY-MM-DD — <이슈 한 줄 요약> [당일성 / 중장기]
- 대상: <자산군 전체 / 특정 종목>
- 소스: <출처> `[1차]`/`[2차]`/`[추정]`
- 자산군 전체 등락인가 개별 종목만의 이슈인가: ...
- 핵심 내용: ...
- 다른 자산군과 반대로 움직였는지: ...
```

### 5. 보고
신규 모드면 자산군별 개요를 요약해서 보여준다. 갱신 모드면 새로 추가된 이슈만 요약한다. 특정 종목에 계속 관심이 생기면 `/context-layer-builder`로 그 종목을 `context.md`에 등록하라고 안내한다.

## 금지

- 라벨 없는 수치를 산출물에 쓰지 않는다.
- 매수·매도 추천, 목표가, 기대수익률, **배분 비율**을 생성하지 않는다 — 재료만 정리하고 배분은 참가자가 정한다.
- SNS·커뮤니티 등 라벨을 붙일 수 없는 소스는 쓰지 않는다.
- 확인 안 된 걸 지어내서 항목을 억지로 다 채우지 않는다 — 안 되면 `unknown`.
