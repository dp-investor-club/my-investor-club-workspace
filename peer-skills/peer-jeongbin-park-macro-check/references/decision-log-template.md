# 판단 로그(Decision Log) 템플릿

한 건 = 한 지표에 대한 참가자의 판단 한 번, 출처 라벨과 함께 완결된 하나의 기록 단위.

이 파일은 macro-check SKILL.md 6번(판단)과 0번(사후 대조)에서 참조한다. 판단 자체를 다시 쓰게 하지 않는다 — 대상/방향+기간/근거/틀렸다는 신호 네 가지를 참가자의 원문 그대로 먼저 받고, 나머지 칸은 그 뒤에 채워서 확인만 받는다.

## 작성 시 (판단 시점, 6번 절차)

- **날짜 / 지표**:
- **인용한 근거** (각각 라벨 필수):
  - 컨센서스: {값} `[2차]` (출처: ...)
  - 실제값: {값} `[1차]` (출처: ...)
  - 서프라이즈: 상회/하회/부합 or `unknown`
- **나의 판단** (아래 네 가지를 순서대로 하나씩 묻고, 각각 원문 그대로 받아 적는다 — 대필 금지, AI가 요약해서 합치지 않는다):
  - **대상** (무엇에 대한 판단인지 — 예: "원/달러 환율", "코스피", "미 국채 10년물"):
    > "..."
  - **방향 + 기간** (예: "2주 이내에 오를 것"):
    > "..."
  - **근거**:
    > "..."
  - **이게 틀렸다는 신호는 무엇일지** (falsification signal — 나중에 스스로 대조할 기준):
    > "..."
- **사후 대조 예정일**: 위 "방향 + 기간"에서 참가자가 말한 기간으로 우선 계산 (예: "2주 이내" → 작성일+14일). 기간이 없거나 파싱 안 되면 다음 동일 지표 발표일, 그것도 안 되면 `unknown` + 확인 방법.

## 대조 시 (예정일 도래 후, 0번 절차) — 결론 없음, 나란히만

| 항목 | 그때 (판단 시점) | 지금 (실제) |
|---|---|---|
| 컨센서스/실제값 | | |
| 나의 판단(대상/방향+기간/근거, 원문·수정 안 함) | | (참고용) |
| 그때 적은 "틀렸다는 신호" | | 그 신호가 실제로 나타났나? |
| 그때 unknown이었던 것 | | 지금 확인됐나? |

마지막 질문 (AI가 답하지 않고 참가자에게 넘김):
> "그때 근거가 지금 봐도 말이 되나요? (결과가 맞았는지가 아니라 그때 근거가 지금 봐도 타당한지)"

참가자의 답을 받아 적으면 대조 완료. `context.md`의 "판단 로그 진행" 표에서 해당 행의 "대조 완료"를 채운다.
