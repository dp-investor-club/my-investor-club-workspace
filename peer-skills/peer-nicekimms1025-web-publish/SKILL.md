## 이 스킬은
- 어떤 병목: 지금까지 만든 산출물을 파일로만 갖고 있어서 남에게 웹으로 공유하기 어려움
- 입력 → 남는 것: 마크다운 파일 하나(기본값 context.md) 넣으면 → 공유 가능한 Vercel URL 하나
- 설치 후 첫 실행: "배포해줘"
- 아직 안 되는 것: 비공개(암호 보호) 배포는 아직 안 됨 — 링크를 아는 사람은 누구나 볼 수 있다

# web-publish — 산출물을 웹 링크로

> 첫 실행 예시: "배포해줘" (기본값: context.md 전체)

## 절차

1. 배포할 파일을 확인한다. 참가자가 특정 파일을 지정하지 않으면 `context.md`를 기본값으로 쓴다.
2. `outputs/_deploy/index.html`을 만든다 — 원본 마크다운 텍스트를 HTML 특수문자만 이스케이프해서 `<pre>` 안에 그대로 넣는 최소 페이지다(마크다운 렌더링 변환은 하지 않는다). 제목은 파일의 첫 줄(`# ...`)을 그대로 쓴다.
3. `vercel outputs/_deploy --prod --yes` 로 배포한다. 처음 실행이라 프로젝트가 링크되어 있지 않으면 이 명령이 자동으로 새 프로젝트를 만든다.
4. 배포 명령 출력에서 URL을 찾아 참가자에게 그대로 보여준다.
5. 참가자 동의를 받으면 `journey.md`에 날짜와 함께 한 줄로 남긴다: `- (YYYY-MM-DD) 웹 배포: <URL> (<배포한 파일명>)`

## 규칙

- 배포 전 참가자에게 **이 URL은 링크를 아는 사람 누구나 볼 수 있다**는 점을 반드시 알린다. 민감한 내용이면 배포하지 않는다.
- `outputs/_deploy/`는 매번 새로 만드는 임시 빌드 폴더다 — git에는 커밋하지 않는다(`.gitignore` 처리됨).
- 크레덴셜·계좌 정보가 담긴 파일은 배포하지 않는다(CLAUDE.md 절대 규칙 4).
- 투자 조언(매수·매도·목표가)이 원본에 없어도 배포 과정에서 새로 추가하지 않는다 — 있는 그대로만 옮긴다.
