# peer-skills — 동료가 만든 스킬

Week 4에서 참가자가 만든 스킬이 여기 모입니다. 폴더 이름 규칙: `peer-{ID}-{스킬이름}/`

**👉 무엇이 있는지, 무엇을 받을지는 [`INDEX.md`](INDEX.md) 를 보세요.** 병목별로 묶어 놓았고, 각 스킬의 첫 실행 한 줄과 받기 전에 준비할 것이 표에 있습니다.

## 받는 법

```
/update
```
```
동료 스킬 중에 peer-nicekimms1025-industry-map 받아줘
```

- **여기 있는 것은 클럽 스킬이 아닙니다** — `.claude/club-skills.txt` manifest에 없으므로 `/update`가 자동으로 전부 받아가지는 않습니다. 고른 것만 받습니다.
- 받으면 `.claude/skills/peer-{ID}-{스킬이름}/`에 저장되고, `peer-` 접두어가 유지되어 여러분 스킬과 섞이지 않습니다.
- 각 SKILL.md 맨 위 "이 스킬은" 4줄이 설치 안내입니다. 그 한 줄대로 실행해보고 **안 되면 그게 원저자에게 줄 데이터입니다** — 대신 고치지 마세요.

## 왜 PR이 안 닫혔는데도 여기 있나

Week 4에 올라온 PR 중 일부는 스킬 파일 외에 개인 상태 파일(`CLAUDE.md`·`journey.md`·`context.md`)까지 함께 담겨 있어 그대로 merge하면 다른 사람의 작업실을 덮어씁니다. 그래서 **스킬 부분만 뽑아 여기에 배치**했습니다. 원 PR은 그대로 열려 있으니, 만든 사람은 자기 브랜치를 계속 쓰면 됩니다.

내용은 원저자가 쓴 그대로이며 클럽이 고치지 않았습니다.
