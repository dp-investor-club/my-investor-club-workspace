# peer-skills — 동료가 만든 스킬

Week 4부터 참가자가 만든 스킬이 PR로 여기에 모입니다. 폴더 이름 규칙: `peer-{ID}-{스킬이름}/`

- **여기 있는 것은 클럽 스킬이 아닙니다** — `.claude/club-skills.txt` manifest에 없으므로 `/update`가 자동으로 받아가지 않습니다.
- 받고 싶으면 `/update`에게 "동료 스킬 보여줘"라고 하세요. 고른 것만 `.claude/skills/peer-{ID}-{스킬이름}/`에 저장되고, `peer-` 접두어가 유지되어 여러분 스킬과 섞이지 않습니다.
- 각 SKILL.md 맨 위 "이 스킬은" 4줄이 설치 안내입니다. 그 한 줄대로 실행해보고 **안 되면 그게 원저자에게 줄 데이터**입니다 — 대신 고치지 마세요.
