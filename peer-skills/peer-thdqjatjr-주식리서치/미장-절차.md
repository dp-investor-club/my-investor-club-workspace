## 절차

### 1) 종목 확인
- 재무·공시는 폴더 없이도 웹으로 완성된다. 단 **`애널리스트\` 폴더는 반드시 확인**해서 PDF가 있으면
  2번 에이전트에 경로를 넘긴다(§5가 2차 매체 취합 → 원문 기반으로 승격된다).

### 2) 1·2·3번 에이전트 **병렬** 호출
한 메시지에서 Agent 3개를 동시에 띄운다(의존성 없음). 프롬프트에:
- 공통: 종목명(한/영 둘 다) + 티커 + 섹터, **양식 경로**(`양식_US.md`).
- 1번: 자료 폴더 경로(있으면) + 하위 파일 목록.
- 2번: 티커 + 섹터(Peer 선정) + 자료 폴더(애널리스트 PDF 유무).
- 3번: 종목명(한/영) + 티커(검색 힌트).

각 에이전트는 담당 섹션 마크다운 + `[리스크/촉매 재료]` + `## [소스 목록]`을 반환한다. 세 결과를 모은다.

### 3) 4번 편집 에이전트 호출 (취합)
`stock-editor`에 넣는다:
- 메타(종목명·티커·섹터·시장=미국·작성일=`Get-Date -Format yyyy-MM-dd`)
- **양식 경로**(`양식_US.md`) — 반드시 명시한다
- 1·2·3번 반환 **원문 그대로**

편집 에이전트는 **완성 리포트 전문** + 끝에 `[검수 메모]`를 반환한다.

### 4) 저장 (오케스트레이터가 직접)
- `[검수 메모]`는 떼어 낸다(파일 미포함). 코드펜스로 감싸져 오면 벗긴다.
- 저장 경로의 하위 폴더가 없으면 만든다(`New-Item -ItemType Directory -Force`).
- 같은 날 재실행이면 파일명 끝에 `_2` 등을 붙여 덮어쓰지 않는다.
- 프론트매터(투자의견·목표주가·현재가·시총·상승여력·환율기준 등) 채워졌는지 확인 후 Write.
- **`공시\소스목록.md`도 쓴다**(국내는 사용자가 직접 자료를 넣으므로 불필요, 미장 전용).
  1·2·3번이 반환한 `## [소스 목록]` 블록을 합쳐 아래 형식으로 저장한다(같은 종목 재실행이면 날짜별로 이어 붙인다):
  ```
  # <종목명>(<티커>) 소스 목록

  ## <작성일> 실행
  ### 저장된 원문 (교차검증 가능)
  - 공시\NVDA_10K_FY2026.txt — 10-K, 2026-02-26 접수 — §2·§3·§4 근거 — <SEC URL>
  ### 조회만 (파일 없음, 링크로 확인)
  - stockanalysis /financials/?p=quarterly — 2026-07-18 — §3-1 분기 실측 — <URL>
  ### 사용자 업로드
  - 애널리스트\<파일명>.pdf — §5 근거
  ```

### 5) 마무리 보고
- 저장 경로를 알리고, `[검수 메모]`(부족 자료·보완분·확인 필요 수치)를 짧게 전달한다.
- **"국장 리포트에는 있었는데 이번엔 없는 자료"를 반드시 먼저 말한다.** 특히 **셀사이드 리포트 원문이 없으면**
  (애널리스트 폴더에 PDF 없음) §5가 2차 매체 취합으로 대체됐다는 사실과 그 한계(날짜 부정확·산출 논리 부재·
  하향 리포트 누락 가능성)를 명시하고, 한경컨센서스 PDF를 자료 폴더에 넣으면 보완된다고 안내한다.
  자료 결핍을 조용히 넘어가지 않는다.
