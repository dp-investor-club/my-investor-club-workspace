## 절차

### 1) 종목 확인
- 자료 루트 아래 재귀 검색(`Get-ChildItem -Recurse -Directory`)해 종목 폴더를 찾고, 있으면 경로에서 섹터를 딴다.
- 폴더를 못 찾으면 사용자에게 알리고 뉴스·FnGuide만으로 진행할지 확인한다.

### 2) 1·2·3번 에이전트 **병렬** 호출
한 메시지에서 Agent 3개를 동시에 띄운다(의존성 없음). 프롬프트에:
- 공통: 종목명·종목코드·섹터, **양식 경로**(`양식.md`).
- 1번: 자료 폴더 경로(있으면) + 하위 파일 목록.
- 2번: 종목코드 + 섹터(Peer 선정) + 자료 폴더(있으면).
- 3번: 종목명(+영문명·자회사명 검색 힌트).

각 에이전트는 담당 섹션 마크다운 + `[리스크/촉매 재료]`를 반환한다. 세 결과를 모은다.

### 3) 4번 편집 에이전트 호출 (취합)
`stock-editor`에 넣는다:
- 메타(종목명·종목코드·섹터·시장=국내·작성일=`Get-Date -Format yyyy-MM-dd`)
- **양식 경로**(`양식.md`) — 반드시 명시한다
- 1·2·3번 반환 **원문 그대로**

편집 에이전트는 **완성 리포트 전문** + 끝에 `[검수 메모]`를 반환한다.

### 4) 저장 (오케스트레이터가 직접)
- `[검수 메모]`는 떼어 낸다(파일 미포함). 코드펜스로 감싸져 오면 벗긴다.
- 저장 경로의 하위 폴더가 없으면 만든다(`New-Item -ItemType Directory -Force`).
- 같은 날 재실행이면 파일명 끝에 `_2` 등을 붙여 덮어쓰지 않는다.
- 프론트매터(투자의견·목표주가·현재가·시총·상승여력 등) 채워졌는지 확인 후 Write.

### 5) 마무리 보고
- 저장 경로를 알리고, `[검수 메모]`(부족 자료·보완분·확인 필요 수치)를 짧게 전달한다.
