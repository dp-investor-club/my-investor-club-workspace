# weeks/ — 내가 채우는 주차축

`club/week-0N/` 이 클럽이 부어주는 자리라면, 여기는 **그것이 내 것으로 바뀌는 자리**입니다.

```
weeks/week-0N/
```

폴더만 있고 안은 비어 있습니다 — 의도된 것입니다. 무엇을 넣을지는 여러분이 정합니다.

## 여기에 들어가면 좋은 것

- 강연·수업을 **내 언어로** 다시 쓴 노트 (원본 복사 아님 — 옮겨 적는 게 아니라 다시 쓰는 것)
- 그 주 과제와 그 과정에서 만든 것
- 그 주에 생긴 질문, 아직 안 풀린 것
- 사전 조사 발표 재료

## 왜 원본을 복사하면 안 되는가

원본은 이미 `club/week-0N/` 에 있습니다. 복사하면 같은 파일이 두 개가 되고, 둘 중 어느 게 최신인지 아무도 모르게 됩니다. **내 언어로 다시 쓴 것만** 여기에 남기세요 — 그게 원본에 없는 유일한 자산입니다.

## 이 폴더와 네 파일의 관계

| 어디 | 무엇 |
|---|---|
| `weeks/week-0N/` | 그 주에 있었던 일 — 시간 순서로 쌓임 |
| `journey.md` | 주차를 관통하는 내 궤적 — 선언, 보강, 세션 노트 |
| `context.md` | 지금 보고 있는 대상의 판단 상태 |
| `CLAUDE.md` | 내 판단 기준 — 매주 한 줄씩 침전 |

주차 폴더는 **그 주에 무슨 일이 있었나**, 네 파일은 **그래서 내가 어떻게 바뀌었나** 입니다. `/session-wrap` 은 앞의 것을 읽어 뒤의 것에 세 줄로 남깁니다.

## 파일 이름

자유입니다. 다만 나중에 찾기 쉬우려면 `날짜-무엇` 형태를 권합니다 — 예: `2026-07-23-병목-정리.md`.
